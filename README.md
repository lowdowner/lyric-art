Lyric Art 

Based on an idea to transpose song lyrics into art featuring geometric shapes by using sentiment analysis to map colours to comma delineated lyrics.
Example shown for 'All Along the Watchtower' by Bob Dylan and famously covered by Jimi Hendrix.
The idea was born of exploration of the condition of <a href="https://en.wikipedia.org/wiki/Synesthesia">Synesthesia</a>, which Hendrix was said to have experienced and in which 'People [...] may experience colors when listening to music, see shapes when smelling certain scents, or perceive tastes when looking at words'

I wanted to use Python to see if it would be possible to generate colours and shapes by parsing text from lyrics, performing sentiment analysis on them and mapping the output score to a colour.
